Step 0
How to use: Pick a color → paint cells → set arrows (click edges) → Solve.
Block: regular sliding block. Chain 🔗: locked, won't move until a 🗝️ key block touches it (chain count times). Key 🗝️: slides normally but unlocks chains on contact.
Arrows push all moveable blocks in that row/col. Blocks that exit the board are cleared. Win = all colored blocks gone.
